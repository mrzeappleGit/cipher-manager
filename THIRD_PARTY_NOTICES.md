# Third-party components

The MIT license in this repository applies to the project's own code. Dependencies retain their own licenses and notices; consult `package-lock.json`, `src-tauri/Cargo.lock` and each dependency's distributed license.

The Windows application uses Tauri, React, TypeScript, Vite, Tailwind CSS, Lucide, Recharts, xterm.js and Rust crates listed in the manifests. Microsoft WebView2 is a separate runtime covered by Microsoft's terms.

Agent CLIs, FFmpeg, Ollama models, WhisperX, LanguageTool/Scribe servers, Porcupine engine/keyword files, Docker, SSH, Tailscale and Proton Bridge are optional external installations. They are not bundled in this beta. Check their respective licenses and service terms before redistributing them or their models.

The schedule tool ships an original neutral SVG placeholder. Custom artwork stays in the user's browser storage; users are responsible for their own uploaded artwork. Previously embedded personal character artwork is excluded from the public distribution.
